### Verification Queries

```sql
-- Check total stories
SELECT COUNT(*) FROM public.stories;

-- View by category
SELECT c.name, COUNT(s.id), 
       AVG(s.accuracy_score), 
       AVG(s.propaganda_score)
FROM categories c
LEFT JOIN stories s ON s.category_id = c.id
GROUP BY c.name;
```
